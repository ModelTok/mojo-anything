## Loop

```sh
mojo-anything record .   # record what the TS code does
mojo-anything build .    # build the the C ABI module
mojo-anything diff .     # run the recorded cases against Rust
mojo-anything shadow .   # run both in the app, log mismatches
mojo-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```
