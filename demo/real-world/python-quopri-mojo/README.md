# python-quopri-mojo

CPython's `quopri` command line (`python3 -m quopri`, the `main()` at the end of
`Lib/quopri.py`) lifted to a pure Mojo binary by mojo-anything. The module's core functions went
through the per-unit loop (`bridge`, `record`, port, `build`, `diff`, `gate`) as a bridged Python
unit, and the command line through the whole-app loop (`app record`, `app front-door`,
`app wire`, `app lift`). The lifted binary answers every recorded case with no Python behind it.

The original is `Lib/quopri.py` from CPython 3.12.3 as Ubuntu 24.04 ships it
(`libpython3.12-stdlib` 3.12.3-1ubuntu0.17, `/usr/lib/python3.12/quopri.py`, SHA-256
`e808f1327b86800e6fcabf98bc194733dbd4348c06d92e8fc9c39829ed477c3b`), copied as `quopri.py` into an
empty folder and run as `python3 quopri.py`. It is not copied here (PSF licence). Usage:
`quopri [-t | -d] [file] ...`.

`quopri.encode`, `decode`, `encodestring` and `decodestring` hand the work to `binascii.b2a_qp`
and `binascii.a2b_qp` (C) whenever `binascii` has them, which CPython's always does, so what was
recorded is binascii's behaviour, not the pure-Python fallback lower in `quopri.py`. The port
follows `Modules/binascii.c`: CRLF output when the first line end is CRLF, soft breaks at 76
columns, `.` alone on a line quoted, `==` decoded as `=`, bad escapes kept.

| Folder | What it is |
| --- | --- |
| `mojo/quopri-mojo` | the bridged unit: `mojo-anything.json` (the manifest; `root` is a placeholder), `port.mojo` (`encodestring`, `decodestring`), `test_port.mojo`, `cases.jsonl` (481 recorded cases), `known-diffs.jsonl` (4, with the reason) |
| `mojo/app-cases` | 163 CLI cases recorded from the original on 2026-11-22 |
| `mojo/app` | the lifted front door: `main.mojo` and `units.mojo` (generated), `glue/quopri.mojo` (written: `main()`'s getopt `td`, each file or stdin, the errors it prints) |
| `inputs.jsonl`, `unit-inputs.jsonl`, `scripts/inputs.py` | the CLI and unit inputs, and the script that wrote them |

`app lift` stripped the unit's bindings (`_native.mojo` and the Python package); `mojo-anything
refresh` writes them again (see Rerun).

## What was run

Mojo 1.2.0, x86-64 Linux (WSL, Ubuntu 24.04), 2026-11-22.

```sh
python3 scripts/inputs.py quopri.py inputs.jsonl unit-inputs.jsonl   # 94 CLI, 322 unit inputs
mojo-anything bridge . quopri.py --keep encode --keep decode --keep main \
  --keep needsquoting --keep quote --keep ishex --keep unhex          # each with its reason
mojo-anything record mojo/quopri-mojo --inputs unit-inputs.jsonl     # 481 cases (155 threw)
# port.mojo and test_port.mojo written; the parameter `s` has no type hint, so the stub had
# `PythonObject`, changed to `List[UInt8]` (bytes) in the port:
mojo-anything refresh mojo/quopri-mojo
mojo-anything build mojo/quopri-mojo
mojo-anything diff mojo/quopri-mojo         # 477/481, then 481/481 (4 by known-diffs.jsonl)
mojo-anything gate mojo/quopri-mojo         # passed
mojo-anything app record . --inputs inputs.jsonl -- python3 quopri.py   # 163 cases
mojo-anything app front-door .              # 163/163 at 100% fallback
mojo-anything app wire . quopri-mojo --command quopri
# glue written in mojo/app/glue/quopri.mojo, then:
mojo-anything app wire . quopri-mojo        # 163/163 at 0% fallback
mojo-anything app lift .                    # lifted: no item fails (one warns: CI runs app replay)
mv quopri.py quopri.py.hidden
mojo-anything app replay . --build mojo/app/.mojo-anything/build/quopri   # 163/163
```

The port matched every bytes case on its first diff, and the glue passed 163/163 with no fallback
on its first replay.

## The unit cases

481 cases: 322 from `unit-inputs.jsonl` (`encodestring` on 44 byte strings, each with the four
`quotetabs`/`header` combinations and the defaults; `decodestring` on 34, with and without
`header`), the rest generated by `record` for the untyped parameter `s` (strings, numbers, lists,
dicts; 155 cases raise, a `TypeError` in the original and in the bindings). The byte strings cover
all 256 byte values in both orders, NUL, CR alone, CRLF, lines of 75 to 77 characters, `=` runs,
80 spaces and tabs, a lone `.`, the CLI texts below; the encoded ones soft breaks with LF, CRLF and
junk after the `=`, upper- and lower-case hex, bad and truncated escapes, `=` at the end.

The 4 known diffs are `decodestring("x")` with and without `header`: `a2b_qp` also takes an ASCII
`str` (binascii's `ascii_buffer` converter) and returns `b'x'`. A bytes parameter of the port
takes bytes-like objects only (`bytes`, `bytearray`, `memoryview`), as `b2a_qp` does, so the
bindings raise `TypeError`; the command line only ever passes bytes.

## The CLI cases

93 cases from `inputs.jsonl` (94 lines; `decode-roundtrip-polish` is the same case as
`decode-stdin-polish`) and 70 traps `app record` derived (file names with spaces, accents, emoji
and ZWJ sequences, a missing file, `-` twice, empty stdin). Encoding stdin, `-` and files, with
and without `-t`: empty input, `=` signs, trailing spaces and tabs (before a line end and at the
very end), lines of 75, 76, 77 and 200 characters, 60 `é` (escapes across the soft break), Polish
text, emoji, NUL and control bytes, CRLF, a CR alone, a line holding only `.`, underscores, 20,001
bytes, two files, a file then stdin, `--`, an option after a file name (read as a file). Decoding
with `-d` and `-dd`: soft breaks, upper- and lower-case hex, bad escapes, `==`, `=` at the end,
binary output (`=FF`, `=00=FF=00`, all 256 bytes, a PNG header, invalid UTF-8), round trips of
the encoded texts. Errors: missing files (exit 1, the others still encoded), a directory,
`-t -d` and `-td` (mutually exclusive, exit 2), unknown options `-x`, `-tx`, `-h`, `--help` and
`--mode=fast` (getopt's message and the usage, exit 2). 42 cases have an empty stdout by nature
(errors, empty input); the original writes no files.

Not covered: stdin or files that are not UTF-8 text, since `--inputs` carries text (the unit cases
cover every byte value); a file that cannot be read for another reason (the glue then prints
Mojo's error text, not Python's `[Errno 13] ...`); `repr()` of a file name escapes only the
non-printable code points listed in the glue, not every one Python's Unicode table knows.

## Rerun

Put CPython 3.12's `quopri.py` in this folder, then:

```sh
mojo-anything app replay .                      # the original: 163/163
# the unit: set "root" in mojo/quopri-mojo/mojo-anything.json to this folder, then
mojo-anything refresh mojo/quopri-mojo && mojo-anything build mojo/quopri-mojo
mojo-anything diff mojo/quopri-mojo             # 481/481 (4 by known-diffs.jsonl)
mojo-anything gate mojo/quopri-mojo
# the lifted binary:
cd mojo/app
mkdir -p .mojo-anything/build/units/quopri
cp ../quopri-mojo/port.mojo .mojo-anything/build/units/quopri/
touch .mojo-anything/build/units/quopri/__init__.mojo
pixi run mojo build --Werror -I .mojo-anything/build/units main.mojo -o .mojo-anything/build/quopri
cd ../..
mojo-anything app replay . --build mojo/app/.mojo-anything/build/quopri   # 163/163
```

These steps were run from a copy of this folder on 2026-11-22 with the results shown. A lifted
app has no `wire` left to build it, so the package `units.mojo` imports is put together by hand
as above (it is what `app wire` and `app lift` write under `.mojo-anything/build/units`).
