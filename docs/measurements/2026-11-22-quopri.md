A copy of `demo/real-world/python-quopri-mojo` with CPython 3.12.3's `Lib/quopri.py` put in it, run as the demo's README says (Rerun). First the original replays the 163 recorded CLI cases; then the unit is refreshed, built, diffed and gated; then the lifted front door is built and replayed with `quopri.py` moved away. The lifted binary has no fallback hook, so `app replay --build` reports no fallback line (its report says `Fallback rate: not reported by this build`): with the original moved away, every case was answered by the binary itself.

`<work>` is the scratch folder the run used, `<repo>` this repository.
